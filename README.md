# Fit Forge - Fitness Workout Tracker[cite: 1]

A dedicated web application designed to help users structure training routines, log daily exercises, and track progressive overload in one place[cite: 1].

---

## Features

- **Workout Logging:** Record workout details including exercises, sets, reps, and target loads.
- **Routine Management:** Organize daily training schedules and structured workout splits.
- **Progress Tracking:** Review completed workout logs to maintain training consistency.
- **Responsive Layout:** Minimal, distraction-free interface optimized for fast inputs during training sessions.

---

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (or specify framework, e.g., React / Vite)
- **Data Persistence:** LocalStorage / IndexedDB (or backend API/Database if integrated)
- **Deployment:** Vercel / GitHub Pages
